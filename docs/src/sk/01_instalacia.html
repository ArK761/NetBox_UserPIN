Čo plugin potrebuje a čo pridá do NetBoxu

Kto: správca servera (prístup k príkazovému riadku a k configuration.py).
Kedy: pred prvou inštaláciou; pri každej aktualizácii pluginu alebo NetBoxu.
Závisí od: NetBox 4.7.0 alebo novší, Python 3.12+, bežiaci worker netbox-rq, prístup na internet (GitHub, PyPI) pri inštalácii.

Požiadavky

ČoPodrobnosti
NetBoxverzia 4.7.0 a novšia (plugin má min_version = 4.7.0 a hornú hranicu nemá). Ak starší NetBox, plugin sa nenačíta.
Python3.12 alebo novší (requires-python >= 3.12).
Worker netbox-rqPlugin si registruje systémovú úlohu User PIN role housekeeping, ktorá beží každých 5 minút. Spracúva vypršané pozvánky, presuny a výnimky, posiela pripomienky, vracia práva po dočasnom odovzdaní, oznamuje koniec platnosti prístupov len cez PIN a posiela zhrnutia zmien. E-maily o zmenách osoby len s PIN-om idú tiež cez frontu default. Keď worker nebeží, tieto veci sa nevykonajú.
Databázatabuľky pluginu vytvorí migrate (migrácie 0001 až 0046).

Pozor: inštalácia s voľbou --no-deps závislosti neinštaluje. Na serveri, kde plugin ešte nebol, ich nainštaluj osobitne (pozri kapitolu Inštalácia).

Čo plugin pridá do NetBoxu

  • Menu „User PIN“ s položkami: Môj PIN, Moje roly, Môj prístup, Test odomknutia, Ľudia len s PIN-om, Používatelia, Oddelenia, Chránené oblasti, Schvaľovania (štyri oči), Audit log, Nastavenia, Mail, CORE (zástupcovia). Ktorú položku vidí ktorý používateľ, závisí od jeho roly (opisuje to kapitola o rolách).
  • Adresa pluginu: /plugins/user-pin/.
  • Dva middleware, ktoré sa zaradia automaticky: PluginLanguageMiddleware (jazyk stránok pluginu) a AreaGuardMiddleware (strážca chránených oblastí a globálnej ochrany). Do configuration.py sa nezapisujú.
  • Tri typy udalostí v notifikáciách NetBoxu (zvonček): PIN four-eyes approval requested, PIN area access requested, PIN role / department change.
  • Oprávnenia NetBoxu s názvami User PIN: … (zástupcovia, editori nastavení, oddelenia). Plugin ich vytvára a spravuje sám: neupravuj ich ručne.

Inštalácia

Kto: správca servera (root alebo sudo).
Kedy: raz, na každom serveri NetBoxu zvlášť (test, produkcia).
Závisí od: kapitola Čo plugin potrebuje; vygenerovaný kľúč (nasledujúca kapitola).

1. Balíky

source /opt/netbox/venv/bin/activate
pip install "argon2-cffi>=23.1" "cryptography>=42" "segno>=1.5" "holidays>=0.50"
pip install --upgrade --force-reinstall --no-deps "git+https://github.com/ArK761/NetBox_UserPIN.git@3.1.0"

Namiesto @3.1.0 môžeš použiť ľubovoľný tag alebo commit. Pip môže po inštalácii napísať upozornenie o python-dateutil (pozri Riešenie problémov): je neškodné.

2. Šifrovací kľúč

Vygeneruj ho a ulož si ho bokom, skôr než plugin zapneš. Postup je v kapitole Šifrovací kľúč.

3. Konfigurácia

V /opt/netbox/netbox/netbox/configuration.py pridaj 'netbox_user_pin' do PLUGINS a blok do PLUGINS_CONFIG:

PLUGINS = [
    # ... tvoje ostatné pluginy ...
    'netbox_user_pin',
]

PLUGINS_CONFIG = {
    # ... nastavenia ostatných pluginov ...
    'netbox_user_pin': {
        'encryption_keys': {'k1': '<tvoj kľúč>'},
        'active_key_id': 'k1',
    },
}
Pozor na dva bloky. Ak už v PLUGINS a PLUGINS_CONFIG iné pluginy máš, riadok a blok sa pridajú, neprepisujú sa. Skontroluj aj čiarky a apostrofy: chyba v súbore zastaví celý NetBox.

4. Migrácie a reštart

cd /opt/netbox/netbox
python manage.py migrate netbox_user_pin
sudo systemctl restart netbox netbox-rq

Príkaz migrate netbox_user_pin vytvorí tabuľky pluginu. Ak hlási No installed app with label 'netbox_user_pin', plugin nie je v zozname PLUGINS.

5. Kontrola, že všetko beží

python manage.py showmigrations netbox_user_pin | tail -3      # všetky riadky majú [X]
python manage.py userpin_check                                  # po čerstvej inštalácii: OK: 0 ... failed: 0
systemctl is-active netbox netbox-rq                            # active, active

V NetBoxe sa v menu objaví User PIN. V Nastavenia je karta Šifrovací kľúč s aktívnym kľúčom a jeho odtlačkom.

6. Prvé kroky v rozhraní

  1. Prihlás sa ako superuser → User PIN → Môj PIN → Nastaviť PIN a Nastaviť 2FA (administratívne akcie vyžadujú 2FA).
  2. Na stránke Mail nastav odosielanie a over aspoň jednu doménu (pozri kapitolu E-maily).
  3. Na stránke Používatelia povoľ používanie PINu tým, ktorí ho majú mať.

Čo sa stane, keď je konfigurácia zlá

Plugin pri štarte overí kľúče a NetBox sa nespustí, ak je s nimi problém (nikdy sa kľúč nevygeneruje ani neprepne potichu). Preto vždy po úprave configuration.py sleduj journalctl -u netbox -n 50.

Aktualizácia pluginu a NetBoxu

Kto: správca servera.
Kedy: pri novej verzii pluginu alebo NetBoxu.
Závisí od: zálohu databázy (pred migráciou), pripnutú verziu v local_requirements.txt.

Aktualizácia len pluginu (jeden riadok)

sudo bash -c 'source /opt/netbox/venv/bin/activate && pip install --upgrade holidays && pip install --upgrade --force-reinstall --no-deps "git+https://github.com/ArK761/NetBox_UserPIN.git@<tag-alebo-commit>" && cd /opt/netbox/netbox && python manage.py migrate netbox_user_pin && systemctl restart netbox netbox-rq'
Produkcia: pred migráciou urob zálohu databázy, napríklad sudo -u postgres pg_dump netbox | gzip > /root/netbox-$(date +%F-%H%M).sql.gz. Kľúče v configuration.py pritom nemeň.

Upgrade samotného NetBoxu

upgrade.sh vytvorí virtuálne prostredie znova a nainštaluje len to, čo je v requirements.txt a local_requirements.txt. Plugin, ktorý tam nie je, po upgrade zmizne. Riadky v /opt/netbox/local_requirements.txt:

netbox-librenms-plugin
netbox-qrcode
git+https://github.com/ArK761/NetBox_UserPIN.git@3.1.0
  • Balík z PyPI stačí zapísať samotným menom. Plugin z GitHubu potrebuje celý odkaz.
  • Riadok bez @… nainštaluje posledný commit vetvy main (nie posledný release; pip GitHub Releases nepozná, pozná len vetvy, tagy a commity). Ak je kód plugin na inej vetve, ponechaj pripnutý commit.
  • Po upgrade skontroluj verzie pluginov (odznak User PIN vX · commit) a spusti userpin_check.

Používatelia (stránka PINov)

Kto ju vidí: CORE (master a zástupcovia) všetkých; vedúci a delegáti len svoje oddelenie. Bežný používateľ stránku nemá.
Kedy: pri správe PINov: povoľovanie, resety, pozastavenie, zrušenie zablokovania.
Závisí od: rola správcu (kapitola Roly); potvrdenie PIN alebo PIN + 2FA pred prvou akciou.

Menu User PIN → Používatelia, nadpis PINy používateľov.

Filtre

  • Hľadanie (meno, e-mail).
  • Stav: Všetci / PIN aktívny / Zatiaľ bez PINu / Bez 2FA / Problém s e-mailom (chýba alebo doména) / Zablokovaní / Pozastavení / Nepovolení.
  • Oddelenie: všetky / bez oddelenia / konkrétne. Rola: všetky / master / vedúci / delegát / pozvaný / bez roly.
  • Zobrazenie: Zoznam alebo Podľa oddelení (strom: vedúci → delegáti → členovia; farby oddelenia: zelená = vedúci a aspoň 2 delegáti, žltá = chýbajú delegáti, červená blikajúca = chýba vedúci).

Akcie pri používateľovi

AkciaPotvrdenieČo urobí
Povoliť / Zakázať / Podľa predvoleniaPINnastaví príznak používateľa (viď tabuľku v kapitole Môj PIN). Pri zapnutých štyroch očiach s kategóriou „povoľovanie PINu“ vytvorí žiadosť

Reset 2FAPIN + 2FAspustí reset; používateľ ho potvrdí PINom a nastaví 2FA na novom telefóne

Pozastaviť / Zrušiť pozastaveniePIN + 2FAPIN okamžite zablokuje (podozrenie z úniku, neprítomnosť), sám, bez druhej osoby; používateľ dostane e-mail
Zrušiť zablokovaniePINzruší zablokovanie po zlých pokusoch
Vynútiť zmenuPINpri ďalšom použití musí používateľ zmeniť PIN

Reset nikdy neprezradí nový PIN správcovi. Reset začne správca a dokončí ho používateľ sám.

Kto koho smie spravovať

SprávcaKoho smie spravovať
Master (superuser)všetkých okrem seba
Zástupca COREvšetkých okrem mastera, iných zástupcov CORE a seba
Vedúci oddeleniačlenov svojho oddelenia okrem seba a iných vedúcich
Delegát oddeleniačlenov svojho oddelenia, ktorí nemajú žiadnu rolu

Nikto nespravuje sám seba (svoj PIN mení v Môj PIN). Pri pokuse o zakázanú akciu stránka odpovie: Delegáti nemôžu spravovať mastera, iných delegátov ani seba.

Núdzový reset 2FA

V menu Akcie pri používateľovi je Núdzovo: príkaz na serveri (2FA): hotový príkaz userpin_reset_2fa na spustenie ako root. Použi ho len keď bežný postup (reset potvrdený používateľom PINom) nie je možný. 2FA sa odstráni okamžite a udalosť sa zapíše do auditu.

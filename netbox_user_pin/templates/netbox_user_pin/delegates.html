What delegates can do

  • See all users' PIN status, the audit log and the settings.
  • Allow / deny PIN use, reset PIN or 2FA, force a PIN change, clear lockouts – after confirming with their own PIN + 2FA.
  • Edit settings only when "Can edit settings" is on.
  • They can not manage the master, other delegates or themselves, and cannot manage delegates.

Implemented as NetBox object permissions "User PIN: delegates …" (kept in sync automatically).
